⚡ Electricity Billing System with GUI (Java)

📌 Overview : 
This project is a group assignment for developing an electricity billing system using Java. The system was upgraded from a console-based application to a GUI-based application using Java Swing. It also demonstrates key Object-Oriented Programming (OOP) principles and exception handling.

This repository highlights my individual contribution within the group project.

🎯 Objectives : 
1) Develop a GUI-based electricity billing system
2) Apply OOP concepts in a real-world application
3) Implement exception handling for input validation
4) Reuse and enhance code from Assignment 1
5) Improve system usability through Java Swing interface

👥 Group Project Note
This is a group assignment. My individual contribution includes:
1) GUI development using Java Swing
2) Implementation of input validation and exception handling
3) Integration of billing calculation logic

⚙️ Key Features
1) Electricity bill calculation (including SST & KWTBB)
2) User record management using array of objects
3) Exception handling for invalid inputs
4) Reusable logic from Assignment 1

🧠 OOP Concepts Used
Encapsulation – Data protection using private variables and getters/setters
Abstraction – Separation of logic into methods and classes
Inheritance – Code reuse through parent-child class structure
Polymorphism – Method overloading/overriding for flexibility

🧱 Technologies Used - 
Java, Java Swing (GUI), Object-Oriented Programming (OOP)
